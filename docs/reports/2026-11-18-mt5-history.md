# R07 — Closed daily MT5 history adapter

Date: 18 November 2026. Status: actual demo export validated and imported; daily reference baseline recorded. Trading suitability remains unvalidated.

## Delivery

Added a one-shot EURUSD closed-D1 exporter using an existing user-configured demo session. It writes an atomic common-file JSON bundle containing source/capture metadata, exclusion boundary and up to 1,500 OHLC/volume/spread rows. A bounded Python reader validates structure, timing/order, prices/volumes and manifest consistency, then produces daily research observations with explicit source/calendar limitations.

The CLI defaults to read-only inspection. Explicit import archives the original bundle by hash and adds a daily dataset while preserving historical runs and paper state. The existing compiler helper now selects continuous quotes or one-shot history. See [the source assessment contract](../MT5_HISTORY.md).
