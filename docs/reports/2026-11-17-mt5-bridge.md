# R04 — Read-only MT5 demo quote monitor

Date: 17 November 2026. Status: implemented and verified locally; changes prepared on a feature branch, not yet published.

## Delivery

An MQL5 script reads EURUSD bid/ask on an existing user-configured demo terminal, publishes a one-second common-file snapshot and exposes no trading or credential operation. A bounded, allowlisted Python reader supplies a GET-only loopback endpoint. The dashboard displays source, bid, ask, spread, approximate quote age and connection/freshness states separately from historical reference-rate experiments.

The compilation helper uses an existing Wine installation, stages build outputs under ignored local storage, checks a new EX5 and clean compiler log, and optionally installs the script. A credential-free startup configuration can launch it with the existing terminal session. See [the operating contract](../MT5_BRIDGE.md).

## Evidence

- Existing MT5 build 6323 on Wine 11.22 Staging; MetaQuotes-Demo vendor demonstration server.
- MetaEditor compilation: zero errors and zero warnings. Source SHA-256: `e400669dabc75e5e679851541ab9b0037e9c67f6dcd1eed21f708c7bff0fa903`.
- Real EURUSD snapshot values and source timestamps changed across observations. No quote data is bundled in the repository.
- An initial computer-clock offset caused a stale warning. After the owner corrected the clock, the reader and browser showed fresh updates with approximately one-to-two-second estimated age. This estimate is not a latency benchmark.
- Browser verification showed the quote panel and existing daily experiment results together without modifying research datasets or runs.
- Python suite: 28 tests covering existing research behavior and new reader/API/publication boundaries. JavaScript syntax check passed. MQL5 compilation was local, not part of hosted CI.

## Boundaries and next checkpoint

No account was created, no credentials were exported and no orders were submitted. MetaQuotes-Demo is a vendor demonstration source; broker execution suitability is unvalidated. The bridge exports snapshots, not every tick, and has no historical archive. Quote timing depends on synchronized computer/server clocks. Market closure, disconnects and halted scripts must remain visible rather than being hidden with cached fresh labels.

Next: durable observation collection with gap/duplicate detection, then historical broker-data assessment and a bid/ask-aware simulation contract. Strategy comparison and controlled adaptation follow usable data and time-ordered validation.
